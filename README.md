# Modern Blue Portfolio Website

## Files
- `index.html` — page structure and content
- `style.css` — responsive modern blue styling
- `script.js` — mobile navigation, active section, year, and demo form

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in Chrome (double-click it in File Explorer).
4. For easier development, install the VS Code Live Server extension, right-click `index.html`, and choose **Open with Live Server**.

## Personalize before publishing
Search and replace `Your Name`, `YN`, `your.email@example.com`, and `Your City, Your Country`.
Replace the sample project descriptions with your own projects. Skill bars are illustrative and should be adjusted to reflect your actual experience.

## Publish with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a **public** repository, for example `my-website`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for deployment and open the URL displayed on the Pages settings screen. It generally looks like `https://YOUR-USERNAME.github.io/my-website/`.

The contact form is front-end only: it validates the fields and shows a demo confirmation, but does not send email or store messages. To receive real messages, connect a form service or build a backend.
